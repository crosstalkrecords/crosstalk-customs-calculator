## Input and acknowledgment

The candidate gateway sends JSON with the existing order field names plus three server-generated keys: `Submission ID` (UUID), `Request Fingerprint` (64 lowercase hex characters) and `Artwork Attached` (`Yes` or `No`). The gateway does **not** send its artwork capability or a destination path. Its Make request has the dedicated `x-make-apikey` value, which is never committed here. The gateway accepts only HTTP 200 body **exactly** `Accepted` as queue acknowledgment. A later authenticated callback with the actual Airtable record ID and returned Dropbox Uploads folder establishes completion. Timeout, non-200, or unexpected body means unknown outcome; no automatic gateway replay.
